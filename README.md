# WaveFrontLab

Программный комплекс для анализа интерферограмм датчика волнового фронта на основе эффекта Тальбота. Приложение обрабатывает видео с камеры или из файла, находит интерференционную картину, отслеживает её точки от кадра к кадру и в реальном времени строит 3D-карту искажений волнового фронта.

## Как это работает

Датчик на основе эффекта Тальбота даёт на камере регулярную картину светлых точек. Когда волновой фронт искажается, точки смещаются относительно исходного положения. По этим смещениям и строится карта искажений.

1. **Предобработка кадра.** Яркость, контраст, резкость и шумоподавление. Параметры можно подобрать вручную ползунками или автоматически: Optuna перебирает значения и максимизирует число корректно выделенных точек.
2. **Сегментация.** Перевод в оттенки серого, бинаризация методом Оцу и морфологическая дилатация дают бинарную маску интерференционной картины.
3. **Калибровка (первые кадры).** Преобразование Хафа находит круглую апертуру, внутри неё по моментам контуров вычисляются центры точек. Из калибровочных кадров выбирается тот, где точек найдено больше всего, и он становится опорной конфигурацией.
4. **Отслеживание.** На каждом следующем кадре находятся центры точек, они сопоставляются с опорной сеткой (группировка по строкам и столбцам с порогом), и для каждой точки считается смещение.
5. **Визуализация.** Смещения передаются в 3D-поверхность на VisPy, которая обновляется в отдельном потоке параллельно с GUI.

## Возможности

- Источник: видеофайл (mp4, avi, mov, mkv) или камера в реальном времени с выбором устройства
- Ручная настройка фильтров и автоматический подбор параметров через Optuna
- Выделение области интереса мышью и обрезка кадра
- Пауза, перемотка и навигация по кадрам видео
- Интерактивная 3D-карта искажений, обновляемая в реальном времени

## Структура проекта

```
WaveFrontLab/
├── src/
│   ├── main.py             # точка входа: GUI + поток 3D-визуализации
│   ├── gui.py              # главное окно PyQt6, управление видео и фильтрами
│   ├── video_processor.py  # сегментация, калибровка, отслеживание точек
│   ├── new_dot_sorter.py   # сопоставление точек с опорной сеткой
│   ├── autoParams.py       # автоподбор параметров фильтров (Optuna)
│   ├── camera.py           # поиск камер и диалог выбора
│   └── plt.py              # 3D-поверхность на VisPy
├── resources/              # .ui-файл интерфейса и изображения
├── Dockerfile
├── docker-compose.yml
└── requirements.txt
```

## Запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python src/main.py
```

### Docker (Linux с X11)

Приложение графическое, поэтому контейнеру нужен доступ к X-серверу хоста:

```bash
docker build -t wavefrontlab .
xhost +local:docker
docker run -it --rm \
  -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix \
  wavefrontlab
```

Для работы с камерой добавьте `--device /dev/video0`.
